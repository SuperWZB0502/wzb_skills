# 特性文档 · 01 算子详情

## 一、设计文档

统一入口从 Ascend Profiling 生成一份离线 HTML，结合全局总览、训练并行时间轴和逐卡算子详情。已有解析结果可独立重渲染，便于验证界面改动和复现报告。

## 二、实现文档

- 接入算子详情，支持计算和通信的算子及类型视图、饼图、搜索、排序、分页、明细和全量 CSV 导出。
- 支持单卡平铺导出和训练日志发现。HyperParallel 时间轴使用显式采集标记定位整步前向与反向，重叠通信按时间区间分行。
- 移除在缺少可确认 PP 通信组时显示的通用告警。时间轴默认启用计算、通信和 Free。算子详情的饼图对齐，核占比在右侧饼图上方，`cube` 和 `vector` 同行。表格的加速器核下拉跟随核饼图的勾选和框选范围。
- 全局总览和训练并行时间轴在筛选栏左侧留白显示「本行筛选」手指提示。任一筛选栏首次进入视野时，两处提示同步向右滑动、回到原位并循环，20 秒后一起隐藏。提示使用绝对定位，保持页面宽度和筛选栏位置。浏览器启用减少动态效果时静态显示。
- 训练并行时间轴新增前向和反向逐层标注。前向以显式框架层区间和 `torch_to_npu` 确认归属，反向再结合 `fwdbwd` 和 `Sequence number`。两者均按已归属设备算子的首尾绘制，详情保留 CPU 框架区间。缺少设备关联时注明框架证据。
- 显示标注分为 `1F/1B micro`、`L1F/L1B 层`、`R1 重计算` 和 `opt 优化器更新`。micro 与层分别成组控制正反向，默认开启。
- 旗位行支持鼠标与 `F` 插旗、单旗及批量删除、旗子和区间重命名。选区可两端插旗，事件可按原始起止时间插旗。旗形和色板由 `sync_mindstudio_timeline.py` 从固定的 MindStudio 源码版本提取。
- 旗位、泳道选区和标注的放大共用 `Q`、`E` 缩放历史。时间轴更新了起始、结束、持续时间的顺序，以及边线、浮窗位置和键盘鼠标操作指南。
- 无新增环境变量开关。命令及依赖见 [技能命令说明](../profiling-analysis-skills/references/commands.md)。

## 三、测试文档

使用 `hp_mega_l8_prof` 的已有解析结果执行 `run_analysis.py --render-only --browser-check`。三个功能均通过浏览器验收。时间轴核对默认流及泳道，算子详情核对饼图布局、核预设、勾选、框选和撤销联动。重生成的 HTML 与正式报告逐字节一致。

在 Chromium 核对桌面和窄屏的提示位置，并验证合并报告从任一筛选栏触发时两处提示的同步、20 秒隐藏及滚动后保持隐藏。单功能页面及减少动态效果模式也通过检查。

本次用原始 `hp_mega_l8_prof` 重新生成报告，再从同一输出目录重渲染。首次渲染从解析结果记录的日志目录读取训练参数，两个阶段生成的 HTML 逐字节一致。

```bash
python3 "$SKILL_DIR/scripts/run_analysis.py" --profiling /path/to/profiling --output-dir /path/to/empty-output --workers 1 --browser-check
python3 "$SKILL_DIR/scripts/run_analysis.py" --output-dir /path/to/empty-output --render-only
```

三个功能均通过 Chromium 验收。冷跑与正式报告的 21,223 条时间轴事件、22 个逐层标注、训练参数、操作指南和按钮一致。反向标注仍关联 3,026 个设备算子。72 个文件哈希和 MindStudio 资源提取校验均通过。macOS 触控板和仅通信模式未单独复跑。

层边界修正的浏览器验收逐一核对 14 个前向和 8 个反向层块的设备算子首尾，同时检查 micro 与层独立开关、全选和清空。
