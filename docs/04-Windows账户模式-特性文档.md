## 一、设计文档

- 角色：主特性

### 背景与目标

将运行目录的 Windows 账户模式纳入源代码历史，避免发布后退回旧行为。

### 方案概述

仅在 Windows、显式选择 `account` 且非会议时，将平台所需的主目录和 SSH 代理环境按既有白名单转发。

### 关键设计

### 风险与取舍

账户模式使用当前系统用户权限，不是沙箱；默认保持 `sandboxed`。会议保留原有只读策略。

## 二、实现文档

- 角色：主特性

### 实现概述

### 关键改动

- `runtime-host.ts` 允许 Windows 使用既有 `account` 配置。
- `run-registry.ts` 有条件地转发 Windows 白名单环境，并同步说明工作区与访问权限。
- `codex-account-driver.ts` 通过 Codex 的 shell 环境策略转发上述环境；不记录环境值。

### 配置与开关

复用 `executionMode`，不新增开关，不修改当前运行配置。
