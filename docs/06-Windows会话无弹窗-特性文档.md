## 一、设计文档

- 角色：主特性

### 背景与目标

会话执行器、Codex 账户进程和关联的后台查询未指定隐藏 Windows 控制台，可能在每次会话时弹窗。

### 方案概述

为相关子进程指定 `windowsHide: true`，保留原有标准流和生命周期。

### 关键设计

### 风险与取舍

只隐藏后台子进程窗口，不修改账户权限、沙箱、日志或取消流程。验收如需回滚，仅撤回这些启动参数。
