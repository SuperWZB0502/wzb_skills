## 一、设计文档

- 角色：主特性

### 背景与目标

先完成可独立使用的本机目录浏览器，确定页面、来源选择与常用路径操作。

### 方案概述

聊天页、办公室页和普通会话共用目录面板。收起时只显示左边缘居中的小箭头；主页支持点击空白收起和拖拽调宽，会话箭头位于窗口外侧，点聊天内容不收起。远程选项不发请求。

### 关键设计

- 地址栏支持绝对路径与相对工作区路径；跳转失败保留最后成功显示的目录。
- 主页从工作区或上次路径打开；会话默认打开当前 Agent 的工作目录。相对路径以工作区为基准，跨 Windows 驱动器不提供相对路径。
- 浏览器保存来源、主页宽度和各目录视图。窄屏只临时限宽；单击展收、双击进入或预览。
- Windows 本机直接支持写操作，不覆盖同名目标，也不修改 Web Office 管理数据。优先使用系统回收站；永久删除须输入完整名称确认。
- 白名单内的文本与 Markdown 用弹窗；静态图片直接在新标签页打开原图，不生成缩略图。目录列表不加载文件内容。

### 风险与取舍

目录能力仅在 Windows 运行层提供，不要求另设开关。API 保留配对网页会话、CSRF、回环及同源校验，拒绝常见转发标头；透明 SSH 转发无法仅凭 HTTP 请求识别，不要把本机自用实例转发给他人。回滚可恢复之前的运行文件并重启；无数据迁移。

## 二、实现文档

- 角色：主特性

### 实现概述

使用现有弹窗、工作室请求与剪贴板工具。目录节点首次展开时读取，刷新或跳转重建目录树。

### 关键改动

- `app/server/office/local-file-browser.ts` 列目录，不读取文件正文；会话默认位置由运行层按 Agent 布局解析。
- `app/server/office/local-file-operations.ts` 执行 Windows 新建、复制和删除；目录复制使用 `robocopy`，回收使用 Windows Shell API。
- `app/server/office/local-file-preview.ts` 管理格式白名单并限制读取体积；文本最多 `256 KiB`，静态 PNG、JPEG、WebP 限 `20 MiB` 和 2000 万像素。
- `app/src/office/FileBrowserDialog.tsx` 共用目录面板、路径菜单和拖拽调宽；目录状态与主页宽度存入浏览器。

### 运行要求

Windows 运行层自动向网页公布浏览和写入能力，无目录功能环境变量。其他平台不公布这两项能力。

### 已知限制

远程服务器尚未接入。Windows 网络和设备路径不接受；符号链接显示为链接，不自动在目录树中展开。单个文件夹最多显示首批 5000 项。
