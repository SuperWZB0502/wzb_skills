全局总览

端到端时间 = 计算 + 未掩盖通信 + Free。 时间占比以当前行端到端时间为分母；层数、重计算与显存保持原值。
总通信 = 未掩盖通信 + 掩盖通信。 掩盖通信与计算存在重叠，各时间项不能直接全部相加；“—”表示暂无数据。

数据来源与统计口径

每行保留一张实际采集卡，Stage 单元格可查看原始卡号及流水线分组。时间与百分比均保留两位小数，导出跟随当前显示模式。分母为零时占比显示“—”。显存单位为 GiB，其采集范围以来源说明为准。bubble = PP + Grad AR；时间表最后一列 = 计算 + 未掩盖通信 + Free − bubble；理论 bubble = (PP − 1) / (MBN + PP − 1)。理论比例直接转换为百分比。
