操作指南
  1. 鼠标移入主图即可使用W/S聚焦鼠标平滑缩放，长按加速；A/D左右平移。细小事件合并显示，放大后可选择单个算子。
  2. 普通拖拽框选保持视窗，灰色遮罩之外保留原色；仅统计完整落入框内的事件。
  3. Ctrl+框选命中的完整泳道按原行高重新组合，并打开框选时间窗，保留Stage、Rank及流标识。
  4. Ctrl+点击1f/1b/1r/opt计算范围块，适配该段时间窗；点击范围块可查看其计算量统计。
  5. 短按Esc逐级恢复视窗和泳道；全屏时长按Esc退出全屏。
  6. 悬停色块时预览详情。单击色块在左下角打开详情，可选取文字复制。移到其他色块仍可悬停预览。点击空白清除选择和普通框选。
  7. Stage、卡号、通信组、显示流、标注和通信域均可复选；表格另有事件类型和名称前缀复选。
  8. 悬停算子使用统一详情表；输入/输出序号保留原字段中的空项，通信仅显示有原始证据的信息。
  9. 悬停通信流空白处，浮窗分两行列出已勾选通信域和未勾选通信域。使用复制定位信息获取区间，使用导出筛选CSV保存当前事件。FLOPs未知项不按零处理；区间MFU使用涉及实采卡的BF16/FP16峰值容量。
