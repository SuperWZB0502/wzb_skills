# 功能和固定交互

## 生成链路

首次完整分析由 `ingest_trace.py` 按卡扫描原始 trace 一次，同时供给全局总览和并行通信图的缓存和索引。算子详情单独读取 kernel CSV 或 DB。`run_analysis.py` 使用独立 Python 子进程执行各功能。`assemble_report.py` 按总览、并行图、算子详情的顺序提取本次成功的功能段并原子写入 `report.html`。

页面实现随包携带：

| 内容 | 源文件（相对scripts） |
| --- | --- |
| 全局总览结构、CSS、排序、表格 | `features/overview/script/global_overview.html` |
| 并行图、CSS、SVG/Canvas、筛选、框选和全屏 | `features/parallel/script/parallel_timeline.html` |
| 统一详情表、I/O、FLOPs/MFU、带宽格式 | `features/parallel/script/detail_panels.js` |
| 通信域顺序、颜色、别名和语义 | `features/parallel/script/parallel_domain_registry.py`、`timeline_colors.py`、`mindspeed_domains.py` |
| 真实数据注入 | 各功能的`render_overview.py`或`render_parallel.py` |
| 算子详情和全量分组 | `features/operator/script/run_operator.py`、`operator_data.py`、`operator_details.html`、`operator_details.js` |
| 一次原始扫描及自动并发预算 | `ingest_trace.py`、`worker_budget.py` |
| 功能调度和最终拼装 | `run_analysis.py`、`assemble_report.py` |

固定配色以这些文件为准，Agent不重新选色。两功能最大宽度1600px，配置栏白底黑字；总览交错行为白色/#F8FAFB，行列高亮#F0F8F6、交点#E9F4F1。全部样式和脚本内嵌，无CDN或在线字体。相同输入、参数和版本使用相同规则；系统字体、浏览器和窗口尺寸可能影响截图像素。

## 功能1：全局总览

按实采Step、PP Stage和rank显示时间表与百分比表，包含层数、重计算、显存、计算、未掩盖/掩盖/总通信、Free、端到端、PP/DP/EP/CP/TP、Grad AR、bubble及扣除bubble的有效耗时；百分比模式最后一列为理论bubble。百分比分母为本行端到端。层数、重计算、显存不转百分比。

信息栏显示实采卡数、总卡数、GBS、MBS、MBN、PP、DP、EP、CP、TP及单Step耗时。时间默认秒，单位顺序秒/毫秒/微秒，两位小数；表头排序、全单元格居中、交错浅色行及行列悬停高亮已固化。提供搜索和CSV。

## 功能2：并行通信图

统一图包含计算、通信、拷贝、Free四种流。同一张卡中时间重叠的通信事件排到不同显示行，行号表示图上的排布。左键和右键框选按实际显示行处理。通信域为PP、DP、EP、CP、TP、GLOBAL、TP-Extend-EP、DP-Modulo-EP、DP-With-CP、DP-With-CP-Modulo-EP，存在未知事件时显示「未确认」。各域数据在`domains/`独立保存。共享物理组通过别名关联，选择多个别名不会重复事件。

默认显示计算流、通信流、Free 和前向、反向标注。仅通信报告默认显示通信流。通信域默认选中本报告有事件的类型，无事件的域禁用。重新开启通信流时，恢复所有可用通信域和当前卡号下的通信组。HyperParallel 的 DeviceMesh 轴名可作为通信域语义证据。只有 rank 数的运行时组显示实测大小及候选网格轴，保留未确认状态。

### 操作

- 鼠标移入主图即可用W/S围绕鼠标位置平滑缩放，按住加速；A/D平移，不要求先单击。
- 普通框选保持视窗，显示遮罩、起止线和持续时间，明细仅统计完整落在二维框内的事件。
- 右键框选直接放大。左键框选松手后，从框外左侧或右侧的结束角操作「放大选区」和「左右插旗」。左右都放不下时，入口在图表下方。放大按命中的泳道打开选定时间窗。双击整步、逐层或重计算标注可放大对应区间。
- 新框选的泳道选区支持按 `F` 在两个边界插旗，按 `E` 放大选区。时间轴各放大入口共用历史。按 `Q` 回上一级，300 毫秒内连按两次回全局。未新框选时，按 `E` 恢复下一级，连按两次到最深一级。回退后再次放大会替换原有的前进历史。全屏长按 `Esc` 退出，`W/S` 连续缩放沿用原操作。
- 刻度下的旗位行与时间轴共用底色。单击等待 200 毫秒后插旗，快速双击区间放大，右键可重命名旗子或区间和删除旗子。鼠标位于泳道时按 `F` 在当前游标处插旗，悬停旗子时按 `F` 删除该旗。按住左键拖动旗位行可放大区间，选中旗子时还可批量删除。区间显示时长，有足够空间时同时显示名称。悬停显示完整起止和持续时间。
- 单击时间轴事件块后，通过下方的「左插旗」或「右插旗」在事件的原始起始或结束时间插旗。
- 悬停色块可预览详情。单击后在左下角显示可选取的详情。移到其他色块时仍可悬停预览，左下角保留已选色块的详情。点击图内空白清除选择。
- 不绘制未勾选通信域的灰色虚线提示。悬停通信流空白处只用两行列出当前已勾选、未勾选通信域；不将这些列表解释为该时刻的实际算子归属。
- 卡号悬停列出所选通信域的组及成员。移动对齐虚线上方显示当前时间；色块宽度足够时名字居中，不足时左对齐省略，实际算子名称统一白字。
- f/b为灰色范围标注；r依证据按层分段，在父b内倒序显示L7r、L6r等，父b居中且与r文字分离；opt取主计算流Adam设备事件包络。
- 有明确框架层标记的采集可在 f/b 下显示逐层标注。反向依据 `fwdbwd`、`Sequence number` 和 `torch_to_npu` 展示可确认归层的设备算子覆盖范围。

### 详情和统计

计算详情用总览、输入、输出三张按内容宽度自适应的表。shape 为 `[24576, 4096]`，缺失项为 `-`。总览显示 Stage、Rank、起始、结束、持续时间及有证据的 FLOPs/MFU。输入输出保留原字段空槽位，超宽可横向滚动。

通信详情用总览与传输信息两张表。总览显示 Stage、Rank、类型、域、组、起始、结束、持续时间。持续时间下分传输、等待、总计，传输表显示类型、收发 Rank、通信量、传输时间和带宽。集合通信按本卡到组内其他卡展示组范围。

带宽通常保留两位小数；小于0.01的非零值保留三位有效数字，必要时科学计数法。原始零值显示「采集值为0」，无有效传输记录显示「未记录有效传输」，缺失或无法关联显示`-`。详情、事件明细、CSV使用相同规则。

点击f/b/r及框选范围可统计范围内计算算子的总FLOPs/MFU；未知项明确保留下界。左下详情支持复制区间定位信息及默认收起的Python调用栈。默认事件总览每个Stage/rank一行，事件表格跟随图上的 Stage 和卡号。事件名称搜索框右侧可打开名称前缀复选列表，支持全选和清空。事件明细按框选、事件类型和关键词筛选后的实际结果显示列，有计算事件时显示 I/O、FLOPs 和 MFU，有通信事件时显示通信域、通信组及传输信息。明细支持排序和 10/30/50 条分页。

## 功能3：算子详情

选择卡序号后默认显示「计算算子类型」，另有「计算算子」「通信算子」「通信算子类型」。有机器名称时可切机器。类型统计显示数量、总耗时、平均耗时、最大耗时和最小耗时，支持展开及分页查询组内明细。

耗时图基于当前卡和分组的完整数据，使用 MindStudio Insight 的饼图色板。逐次计算的算子饼图超过 50 项时显示耗时最高的 49 项及 Others。点击 Others 扇区或图例可查看归入该组的算子。悬停会放大扇区，并在指针旁显示耗时和占比。

逐次计算表显示输入输出 Shapes、数据类型、格式和动态 PMU，通信表显示时长和等待。开始时间为相对毫秒，TEXT 以该卡最早有效算子为起点，DB 优先采用会话起点。时长和等待均为微秒。

两张饼图均可按住鼠标左键后沿圆周拖动，松开时保留和框选区域相交的扇区，并同步筛选算子表。百分比继续使用当前卡和分组的全量耗时。「上一级」退回上一次框选或进入 Others 明细之前的范围，「重置」恢复图表初始范围。加速器核图默认全选，支持单独勾选，以及「全选」「清除」「cube」「vector」预设。`cube` 选择 `AI_CORE` 和 `MIX_AIC`，`vector` 选择 `AI_VECTOR_CORE` 和 `MIX_AIV`。图上方的合计占比以本卡计算总耗时为分母，同时考虑勾选和核图框选。

表头和内容左对齐，点击可排序列的表头单元格切换排序，拖动表头右边缘调整列宽。类型和加速器核在同一控件中支持关键词和复选筛选。右侧下拉包含「全选」和「清空」。加速器核下拉只允许选择当前饼图勾选及框选范围内的核，其他核置灰。详情在原行下方独立展开，宽表可横向滚动，缺失值显示为 `N/A`。CSV 下载覆盖当前卡、当前分组的完整结果。HTML 使用内嵌 gzip 数据，无需外部网络资源。

## HTML数据存储

功能2采用gzip压缩的分块列式载荷：重复文本共享字典、标量列使用类型数组、时间保存精确整数基值/差值与原小数位数；嵌套args按需构造，计算I/O引用按事件位置保存。高频绘图字段直接缓存于轻量事件视图，避免缩放与筛选时反复解码。全部事件仍可用于筛选、统计、CSV与详情，不按像素采样丢弃。旧版gzip载荷仍可读取；HTML保持一个文件、离线打开、无外部资源。详情见[HTML性能](html-performance.md)。
