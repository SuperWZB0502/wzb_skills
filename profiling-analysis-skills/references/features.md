# 功能和固定交互

## 生成链路

首次完整分析由`ingest_trace.py`按Rank多进程扫描原始trace一次，同时供给两个功能各自的输入缓存及精确CPU/flow索引。随后`run_analysis.py`用独立Python子进程执行两个功能，分别得到`overview/report.html`和`parallel/report.html`。`assemble_report.py`提取带唯一边界标记的正式功能段，按总览、并行图顺序拼装并原子写入根目录`report.html`。目标旧HTML不参与生成；只包括本次成功的功能。首次执行不依赖调研仓库、模型仓库、缓存、演示HTML或模型生成代码。

页面实现随包携带：

| 内容 | 源文件（相对scripts） |
| --- | --- |
| 全局总览结构、CSS、排序、表格、水印 | `features/overview/script/global_overview.html` |
| 并行图、CSS、SVG/Canvas、筛选、框选、全屏、水印 | `features/parallel/script/parallel_timeline.html` |
| 统一详情表、I/O、FLOPs/MFU、带宽格式 | `features/parallel/script/detail_panels.js` |
| 通信域顺序、颜色、别名和语义 | `features/parallel/script/parallel_domain_registry.py`、`timeline_colors.py`、`mindspeed_domains.py` |
| 真实数据注入 | 各功能的`render_overview.py`或`render_parallel.py` |
| 一次原始扫描及自动并发预算 | `ingest_trace.py`、`worker_budget.py` |
| 功能调度和最终拼装 | `run_analysis.py`、`assemble_report.py` |

固定配色以这些文件为准，Agent不重新选色。两功能最大宽度1600px，配置栏白底黑字；总览交错行为白色/#F8FAFB，行列高亮#F0F8F6、交点#E9F4F1。水印为“王振邦 w00910068”，稀疏斜向半透明，不拦截鼠标。全部样式和脚本内嵌，无CDN或在线字体。相同输入、参数和版本使用相同规则；系统字体、浏览器和窗口尺寸可能影响截图像素。

## 功能1：全局总览

按实采Step、PP Stage和rank显示时间表与百分比表，包含层数、重计算、显存、计算、未掩盖/掩盖/总通信、Free、端到端、PP/DP/EP/CP/TP、Grad AR、bubble及扣除bubble的有效耗时；百分比模式最后一列为理论bubble。百分比分母为本行端到端。层数、重计算、显存不转百分比。

信息栏显示实采卡数、总卡数、GBS、MBS、MBN、PP、DP、EP、CP、TP及单Step耗时。时间默认秒，单位顺序秒/毫秒/微秒，两位小数；表头排序、全单元格居中、交错浅色行及行列悬停高亮已固化。提供搜索和CSV。

## 功能2：并行通信图

统一图包含计算、通信、拷贝、Free四种流；通信域为PP、DP、EP、CP、TP、GLOBAL、TP-Extend-EP、DP-Modulo-EP、DP-With-CP、DP-With-CP-Modulo-EP，存在未知事件时显示「未确认」。各域数据在`domains/`独立保存。共享物理组通过别名关联，选择多个别名不会重复事件。

默认通信流、PP+GLOBAL及f/b标注。取消通信域全选恢复PP+GLOBAL；重新开启通信流也恢复这两个域。顶栏含Step、Stage、卡号、通信组、单位、显示流、显示标注、通信域、图中名称和操作指南/CSV。复选项显示已选/总数，点外关闭；Stage→卡号→通信组级联，选组自动开启对应域。

### 操作

- 鼠标移入主图即可用W/S围绕鼠标位置平滑缩放，按住加速；A/D平移，不要求先单击。
- 普通框选保持视窗，显示遮罩、起止线和持续时间，明细仅统计完整落在二维框内的事件。
- Ctrl+框选：按命中的完整泳道重新组合显示，并打开选定时间窗；保留Stage/Rank及流标识，不进行局部像素拉伸。Ctrl+点击f/b/r/opt适配对应时间窗。
- 短按Esc逐级恢复；全屏时长按Esc退出。全屏按钮位于功能标题行右侧；操作指南按钮位于导出CSV左侧，向上展开并跟随按钮位置。
- 只有一个详细悬浮窗。未选择时跟随鼠标；单击色块后固定在色块旁，缩放、平移及滚动时跟随色块；点击另一色块切换，点击图内空白关闭。原有左下详情保留。
- 不绘制未勾选通信域的灰色虚线提示。悬停通信流空白处只用两行列出当前已勾选、未勾选通信域；不将这些列表解释为该时刻的实际算子归属。
- 卡号悬停列出所选通信域的组及成员。移动对齐虚线上方显示当前时间；色块宽度足够时名字居中，不足时左对齐省略，实际算子名称统一白字。
- f/b为灰色范围标注；r依证据按层分段，在父b内倒序显示L7r、L6r等，父b居中且与r文字分离；opt取主计算流Adam设备事件包络。

### 详情和统计

计算详情用总览、输入、输出三张按内容宽度自适应的表；shape为`[24576, 4096]`，缺失项为`-`。总览显示Stage、Rank、起始、持续、结束及有证据的FLOPs/MFU。输入输出保留原字段空槽位，超宽可横向滚动。

通信详情用总览与传输信息两张表。总览显示Stage、Rank、类型、域、组、起始、传输/等待/总时长、结束；传输表显示类型、收发rank、通信量、传输时间和带宽。集合通信以本卡→组内其他卡展示组范围，不冒充逐链路采样。

带宽通常保留两位小数；小于0.01的非零值保留三位有效数字，必要时科学计数法。原始零值显示「采集值为0」，无有效传输记录显示「未记录有效传输」，缺失或无法关联显示`-`。详情、事件明细、CSV使用相同规则。

点击f/b/r及框选范围可统计范围内计算算子的总FLOPs/MFU；未知项明确保留下界。左下详情支持复制区间定位信息及默认收起的Python调用栈。默认事件总览每个Stage/rank一行，明细提供Stage、事件类型、名称前缀复选、排序及10/30/50条分页；结束列后显示I/O、FLOPs/MFU和通信元数据。

## HTML数据存储

功能2采用gzip压缩的分块列式载荷：重复文本共享字典、标量列使用类型数组、时间保存精确整数基值/差值与原小数位数；嵌套args按需构造，计算I/O引用按事件位置保存。高频绘图字段直接缓存于轻量事件视图，避免缩放与筛选时反复解码。全部事件仍可用于筛选、统计、CSV与详情，不按像素采样丢弃。旧版gzip载荷仍可读取；HTML保持一个文件、离线打开、无外部资源。详情见[HTML性能](html-performance.md)。
