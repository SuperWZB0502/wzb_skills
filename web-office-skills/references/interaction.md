# 聊天、任务、阅读与图片

日常功能总览见 [README](../README.md)；安装、构建、发布和维护命令只在 [workflows](workflows.md) 维护。

## 界面与伙伴

任务动画 `office` 与极简对话 `chat` 互斥加载；切换会卸载上一界面，后台任务继续。动画按真实状态显示角色，经过门和走道；姓名有背景，工作红、会议黄、休息绿，其他状态在信息卡或进度中查看。单击看信息，双击聊天，右键编辑/复制/删除身份。Boss 是固定入口，不可删除或开除。

深色为炭黑灰、浅色为奶白，主题在同一浏览器记忆。办公室含工作、休息、会议、知识库和右下小黑屋；知识库与小黑屋也有普通列表入口。空闲动画不调用模型或消耗模型 token，仍有浏览器绘制和状态同步开销。

身份两阶段处理和永久会话清理不同：删除身份移入小黑屋并保留配置；小黑屋内进一步开除才清配置、退出名单，会话留知识库。详见 [services-conversations](services-conversations.md#dismissed-employees)。

## 聊天与配置

Enter 发送，Alt+Enter 换行；IME 组词时 Enter 只确认候选。会话选择/新建/公司知识库/复制 ID 在一横行，引用按需展开；服务/模型/档位/应用/刷新在另一行，窄屏可横向滚动。

聊天模型从真实服务目录下拉，保留当前模型兜底和读取/失败状态；手填 ID 在身份编辑器进行。选择“稍后配置”可直接应用空配置。Claude 的 1M 选项是用户手动确认服务支持后启用，不探测容量。点击“应用配置”才保存，只影响后续调用；进行中的调用保留原配置。[credentials](credentials.md) 说明凭据和模型边界。

每位伙伴的会话和原生线程独立，切换会话不会停止任务。当前任务若属于另一会话，会明确提示，不借用其摘要或停止入口。关闭聊天、断网、退出网页或换界面也不会自动停止已提交任务，需要结束执行时点停止。每身份排队，无固定全局并发 cap。

## 进度、工具与会议

四个等宽箭头表示接收任务、准备环境、执行任务和完成任务，只将有完成依据的阶段填绿，失败/停止不冒充成功。当前提示和计时紧凑显示，工具/摘要详情默认折叠。每身份最多保留最近 400 条进度，单项详情最多 6000 字符，进行中的同项更新按 250ms 节流，结束状态同步。

进度是结构化、脱敏、有界文本，不是终端录像或完整终端记录；thinking 仅显示通用等待/分析活动，不展示内部推理原文。短暂没有新事件不等于任务已停止。

可选择至少两位空闲伙伴发起会议，他们依次从各自职能提出建议，保留记录并进入会议状态。会议发言不修改项目或委派任务。聊天、任务、会议发言和实际委派会消耗模型用量；动画本身不会。

## Markdown、复制与全屏阅读

助手回复在聊天、会议记录和知识库详情使用同一 Markdown/GFM 排版，支持标题、强调、嵌套/任务列表、引用、链接、表格、行内代码和代码块。用户/系统消息保持普通文本，存储的原始 Markdown 不变，旧回复刷新后即可排版。

代码保留缩进，宽代码/表格可横向滚动。每个代码块右上角都有复制按钮，即使没有语言标记也可用；只复制代码正文，保留换行，不包含语言/围栏/按钮。按钮明确提示成功或失败，失败可重试或手动选择。剪贴板能力受浏览器权限限制，不能未经成功就宣称复制完成。

聊天内容区右上角可全屏阅读，只展开原阅读区，不重新加载会话或启动任务。按 Esc 或“退出全屏”回到聊天；退出阅读全屏不应同时关闭会话窗口。优先原生 Fullscreen API，不可用或拒绝时回退到网页视口。全屏期间代码复制的临时选区留在可见 reader 内，操作后恢复焦点/选区。

原始 HTML 不执行，保留渲染器 URL 过滤；远程 Markdown 图片是按需打开的链接，避免阅读时后台抓取。上传图片仍使用下述受认证附件预览。

## 图片

点击添加图片、粘贴截图或拖入图片，检查预览后发送；可移除草稿或重试失败项，等上传完成再发送。支持文字配图和纯图片。

| 限制       | 值                              |
| ---------- | ------------------------------- |
| 格式       | PNG、JPEG、WebP                 |
| 每张大小   | 最多 5 MiB                      |
| 每张像素数 | 最多 40 MP                      |
| 每次消息   | 最多四张                        |
| 代理请求体 | 最多 32 MiB，包含历史和编码开销 |

附件保存在根内 `agents/<id>/attachments/`，移除草稿预览不等于已删除服务器文件。多轮历史和 Base64 可能让后续请求超限，可减小图片或新建独立会话。实际视觉理解和计费取决于所选服务/模型，不能从上传/预览成功推断。
