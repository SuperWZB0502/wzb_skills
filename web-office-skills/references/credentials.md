# 模型凭据、目录与 1M 配置

在网页“我的模型服务”新建具名服务，明确选择 Codex 或 Claude Code，再选择 API Key 或官方账户认证。包不包含外部 CLI、全局登录或模型凭据；所选服务需要对应 CLI 已在本机安装。安装与运维命令统一见 [workflows](workflows.md)。

## 认证方式与生命周期

| 项目                                    | 保存与使用方式                                                    |
| --------------------------------------- | ----------------------------------------------------------------- |
| 服务名称、地址、执行器、模型与档位      | 根内非秘密配置，重启保留                                          |
| API Key、OAuth token、PKCE/授权临时资料 | 运行期内存，退出/重启后重新提供或授权                             |
| 网页配对登录                            | HttpOnly Cookie；服务器保存验证哈希与固定 30 天期限，可跨重启保留 |
| 会话、原生线程与消息                    | 根内持久化，独立于 Key 和浏览器登录                               |

API Key 模式使用自定义服务地址：Codex 需要 Responses，Claude Code 需要 Messages，仅 Chat Completions 不能直接替代。Key 只填网页密码式表单，不发 agent 聊天、不放命令行/环境模板/浏览器持久存储/全局 CLI 登录文件，也不读取其他人的 auth/settings。

账户模式保存空服务 URL，只走官方端点。Codex 显示本次设备授权地址与验证码并等待后端状态；Claude 打开官方 PKCE 链接，用户将官方页返回的授权码填回专门表单完成兑换。被拦截的弹窗有显式链接回退；打开网站本身不等于登录成功，任意中转地址也不能成为官方 OAuth 入口。

关闭网页、隧道重连或受支持的前端热发布不会清除仍运行的模型凭据；停止/核心重启会清除。退出网页登录仅撤销当前浏览器会话，不自动停止任务或撤销其他浏览器。需要停止执行时使用任务停止控件。

## 服务选择与模型目录

伙伴默认“稍后配置”，选服务后使用其运行期 slot。多个伙伴选择同一服务是明确共享，不会借用无关服务的 Key。选择“稍后配置”可以直接保存空 provider/model/effort，不等待目录或 Key。

模型目录根据服务和凭据读取；缺少权限、服务不提供、返回空或网络失败时，不代表推理一定不可用。聊天使用目录下拉并保留当前模型兜底；需要手填 ID 时在身份编辑器设置。目录可见不证明对应协议或视觉推理成功。

思考档位优先使用服务明确提供的元数据，再使用执行器对应目录；未知信息标为未核实。不要给所有模型套同一组固定档位。不兼容的旧值需要用户明确重选或使用模型默认，不能暗中替换。聊天点击“应用配置”才保存，已开始的调用继续使用其捕获的服务、模型、档位和凭据。

## Claude Code 的 1M 长上下文

身份编辑器与聊天模型行都有手动“1M 长上下文”复选框；仅 Claude Code 显示，有基础模型 ID 才能勾选。目录和输入框显示基础 ID，保存为带上下文标注的 model；已有 `[1M]`/`[1m]` 会回显，取消勾选去掉标注。同服务换模型保留选择，换服务清空，只影响后续任务。

请先确认服务和模型实际支持再勾选。复选框不做能力探测，也不代表百万 token 输入或视觉能力已验证。CLI 上下文标注与上游 wire model 分开处理；自定义 API 模型的辅助调用也绑定所选模型，避免切回未授权的原生 Claude 模型。相关 relay 细节见 [Claude-compatible relays](services-conversations.md#claude-compatible-relays)。

## 兼容中转与视觉

已有兼容服务使用 `ANTHROPIC_AUTH_TOKEN` 时，用户将对应值填入网页 Key；不要导入其原配置文件。受支持的中转 Bearer 与官方 x-api-key 差异由代理处理。Messages 前缀可能位于 `/anthropic`，目录可能在同源 `/v1/models`；实现只在有限同源路径内回退，不伪造固定模型清单。

图片使用受认证的根内附件，经 Codex `--image` 或 Claude stdin image 块送入执行器；实际服务/模型需支持视觉，也可能产生视觉用量。上传成功不代表模型已经理解图片。图片限制和输入方式见 [interaction](interaction.md)。
